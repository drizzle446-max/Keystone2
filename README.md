# Keystone2

Keystone2 是一款 macOS 菜单栏工具，聚合个人高频实用功能：截图标注、OCR 识别、屏幕标注、休息提醒和外接鼠标滚轮方向翻转。

**当前状态：MVP 内部开发构建**

---

## 功能

| 快捷键 / 入口       | 功能                                              |
| -------------- | ----------------------------------------------- |
| 菜单栏            | 当前事项显示（可设颜色）、休息提醒倒计时、hover 显示完整文本               |
| 系统设置           | 外接鼠标滚轮方向翻转（仅鼠标，触控板不受影响）                         |
| `F1`           | 截图 → 原位标注编辑（画笔 / 箭头 / 矩形 / 文字，支持撤销重做，可复制、保存、钉图） |
| `Command + F1` | 截图 → 复制到剪贴板                                     |
| `Option + F1`  | 截图 → 钉为浮动窗口（可移动、缩放、关闭）                          |
| `F2`           | OCR 框选 → 识别文字并复制到剪贴板（失败不覆盖已有剪贴板）                |
| `F3`           | 屏幕标注叠加层（画笔 / 箭头 / 矩形 / 高亮，穿透模式，鼠标高亮，清空，Esc 退出）  |
| 偏好设置           | 快捷键自定义（支持逐项录制、冲突检测、恢复默认）、开机自启动、当前事项颜色           |

所有快捷键均以鼠标所在屏幕为操作目标（支持多屏）。

---

## 环境要求

- macOS 14.0+
- Xcode 15+
- Swift / AppKit

---

## 构建

**Xcode：** 打开 `Keystone2App.xcodeproj`

**命令行：**
```bash
xcodebuild -project Keystone2App.xcodeproj \
           -scheme Keystone2App \
           -configuration Debug \
           build
```

---

## 权限

| 权限 | 用途 |
|------|------|
| 屏幕录制 | 截图（F1、⌘F1、⌥F1）和 OCR（F2） |
| 辅助功能 | 鼠标滚轮方向 Event Tap |
| 通知 | 休息提醒 |

首次使用时，App 会在缺失权限时显示可理解的提示说明。
